# HR-leave-assistant


### 1. Create a virtual environment

macOS/Linux:

```bash
python -m venv .venv
source .venv/bin/activate
```

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Conda alternative:

```bash
conda create -n mcp-llm-connect python=3.11 -y
conda activate mcp-llm-connect
```
